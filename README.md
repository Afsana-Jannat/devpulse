# DevPulse

## Live URL

[link](https://dev-pulse-pink.vercel.app/)

## Features

- User authentication
- Create issues
- Update issues
- Delete issues
- Filtering and sorting

## Tech Stack

- Express
- PostgreSQL
- TypeScript
- JWT
- bcrypt

## Setup

npm install

npm run dev

## API Endpoints

POST /api/auth/signup

POST /api/auth/login

POST /api/issues

GET /api/issues

GET /api/issues/:id

PATCH /api/issues/:id

DELETE /api/issues/:id
